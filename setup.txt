Installing
==========

To build the website out of the templates, we use a thing called Jekyll.

Jekyll is written in Ruby, hence we need to install that first:

Mac (apparently):
brew install ruby

Windows is a pain:
https://www.ruby-lang.org/en/documentation/installation/#rubyinstaller


Now we need to install jekyll:
==============================

https://jekyllrb.com/
gem install bundler jekyll

Running Jekyll
==============

you should be able to navigate into the tmd_conference folder and run

bundle install

and then

Git pull Hugh main - to sync with Hugh 

bundle exec jekyll serve

and then head to

http://localhost:4000/

and the website should be there.

The actual website source is generated automatically and put into the _site folder.


Making changes and syncing them
===============================

navigate to the folder called tmd_conference

make your changes

once you are done, run

git add .

then

git commit -m "and add a nice message here as to what you did"

To sync your changes, run 

git push origin main

To upload to main website:

https://github.com/0Hughman0/tmd_conference/pulls
click new pull request

on the left dropdown select 'demo', on the right, select ismail 'main'

Check that your changes are sane

click create pull request.

Then I think because you are a collaborator on the project, you can also accept your own pull 
request.

This should incorporate your changes and automatically update the website.

This will push your changes to your fork of the website. i.e. the one found at https://github.com/jeffreyyang415/tmd_conference (for Jeffery!)
